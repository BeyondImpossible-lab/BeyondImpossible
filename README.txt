BEYOND IMPOSSIBLE — IPHONE PWA

FILES
- index.html: the app
- manifest.webmanifest: app identity and Home Screen behavior
- service-worker.js: offline support
- icon files: iPhone/Home Screen icons

IMPORTANT
The folder must be uploaded to an HTTPS website. Opening index.html as a local file
does not allow a service worker or proper iPhone installation.

AFTER HOSTING
1. Open the website URL in Safari on your iPhone.
2. Tap Share.
3. Tap Add to Home Screen.
4. Enable Open as Web App if iOS displays that choice.
5. Tap Add.

Your saved quotes are stored in Safari's local storage on that device.
